# Blinkit Sales Analysis Dashboard

## Project Overview
This project focuses on analyzing Blinkit's sales data to identify key business insights related to sales performance, customer behavior, product performance, and marketing campaigns.

The project follows an end-to-end data analytics workflow using Python, SQL, and Power BI.

## Tools & Technologies Used
- Python (Data Cleaning & Preprocessing)
- MySQL (Data Analysis & Querying)
- Power BI (Dashboard Development & Visualization)

## Project Workflow

### 1. Data Cleaning (Python)
- Cleaned raw datasets
- Handled missing values
- Checked duplicates
- Prepared data for analysis

### 2. Data Analysis (SQL)
Performed analysis to answer business questions related to:
- Sales performance
- Product revenue
- Customer segments
- Delivery delays
- Customer feedback
- Marketing campaign performance

### 3. Dashboard Development (Power BI)
Created interactive dashboards:

### Sales & Product Performance
- Revenue and order overview
- Category-wise revenue analysis
- Brand performance
- Product performance
- High margin and revenue analysis

### Customer Insights Dashboard
- Customer segmentation analysis
- Delivery delay analysis
- Negative feedback drivers

### Marketing Performance Dashboard
- Campaign performance comparison
- Revenue and conversion analysis
- Monthly revenue trends

### Business Insights
Key findings and recommendations based on the analysis.

## Key Insights
- Identified top-performing product categories and brands.
- Analyzed factors affecting customer satisfaction.
- Compared marketing campaigns based on business metrics.
- Evaluated products generating high revenue and margin.
